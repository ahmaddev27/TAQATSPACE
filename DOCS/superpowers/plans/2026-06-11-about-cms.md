# Full About-Page CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]` checkboxes. This feature **mirrors the existing landing CMS** — every task names the concrete landing file to read and replicate for `about`. Do NOT invent a new pattern; copy the landing one and swap in the About schema.

**Goal:** Make the entire About page editable from admin (every text field + real uploaded images replacing the placeholders), falling back to today's i18n defaults until content is entered.

**Architecture:** Replicate the landing CMS: a backend `AboutContentService` (blob in the `about` SiteSetting row + image path→URL resolution via `MediaUrl` + image upload), dedicated public/admin About endpoints, a typed `AboutContent`, an `AboutEditor` admin form (bilingual inputs + cropper image fields), and a rewired public About page.

**Tech Stack:** Laravel 13, Next.js 16 App Router, TS, pure CSS. No unit-test runner → verify with `php -l`, `npx tsc --noEmit`, `npm run lint`, `npm run build`, `composer api:docs`.

**Branch:** `feat/about-cms` (already created). **Working dirs:** backend `c:\laragon\www\TaqatSpace\backend`, frontend `c:\laragon\www\TaqatSpace\frontend`.

**The About content schema** (`LocalizedText = {ar?:string; en?:string}`):
```ts
interface AboutStat { value?: string; label?: LocalizedText }
interface AboutValue { title?: LocalizedText; body?: LocalizedText }
interface AboutSection { heading?: LocalizedText; body?: LocalizedText; image?: string; imageUrl?: string }
interface AboutContent {
  eyebrow?: LocalizedText; title1?: LocalizedText; title2?: LocalizedText; lead?: LocalizedText;
  stats?: AboutStat[]; mission?: {title?:LocalizedText; body?:LocalizedText};
  vision?: {title?:LocalizedText; body?:LocalizedText}; valuesTitle?: LocalizedText; values?: AboutValue[];
  sections?: AboutSection[]; cta?: {title?:LocalizedText; body?:LocalizedText};
  image?: string; imageUrl?: string; imageSecondary?: string; imageSecondaryUrl?: string;
}
```
Image path slots to resolve to `*Url`: `image`, `imageSecondary`, and each `sections[i].image`.
